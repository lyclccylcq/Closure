# 日常动作与桌面走动

当前默认桌宠已换成[新版透明动画](character/new-model.md)：支持待机、思考、说话、情绪、点击及普通拖动。新版没有行走或睡姿，菜单不提供行走与自主走动。下文描述保留在 `codex/legacy-spine-pet-20261127` 分支及显式 Spine 模式中的旧版骨骼行为。

默认开启“自主走动”：清醒且空闲时停留约 20–35 秒，随后用原 Spine `Move` 动作左右走动 4–7 秒，速度约每秒 40 个桌面逻辑像素。她保持当前高度，在所在屏幕扣除菜单栏、Dock 或任务栏后的区域内活动，到左右边缘会转身，朝向随行进方向改变。

右键菜单的“动作 → 行走”会立即开始一小段实际走动。“动作 → 自主走动”可以随时关闭或开启自动行为；关闭后仍可手动“行走”。此开关只影响本次运行，重新启动默认开启。“待机”和“休息”会停止当前走动。

聊天窗口打开、思考或说话、触碰、按住/拖动、鼠标停在模型上、打开右键菜单时会暂停移动；恢复空闲后重新等待，不立即追走。气泡随桌宠一起移动。手动拖到另一块屏幕后，后续使用新屏幕的可用区域，不自主跨屏。

自主走动不算用户活动，不重置此前的两分钟长待机睡眠计时，也不会叫醒睡着的角色。真实点击、拖动、显式“行走”或打开聊天仍按已有规则唤醒。休眠或定时器长时间停顿后不会补算一大段位移。

原 Spine 渲染、聊天坐姿、长待机睡觉、触碰台词缓存和语音模型保持原有行为；走动不调用 AI 或语音接口。

## 点击、拎起与对话过渡

左键按住时会有轻微受力准备；移动超过约 3 个桌面逻辑像素后进入拖动。拖动采用后颈附近作为受力支点：头颈保持相对稳定、略微低头，躯干和放松的四肢垂在下方，身体随移动方向小幅轻摆。提起幅度适中，提起和松开时有短暂缓动。鼠标停住后，摆动逐渐收回。窗口仍保留最初点击的位置偏移，不改变鼠标的抓取位置，也不使窗口整体跳移。

向右拖动时人物朝左，向左拖动时朝右；约 4 个桌面逻辑像素的水平移动才改变朝向，轻微抖动、停住和上下拖动时保持朝向。姿态摆动会按显示朝向换算，身体仍在拖动方向后方轻摆。松手后有约 0.38 秒的落地／屈膝回弹，保留最后的拖动朝向，随后恢复当前的待机、说话或对话坐姿；下次行走时再按行走方向转身。拖动期间不会自主走动；拖走后即使回到按下的位置，也不会把松手误判为触碰台词。右键菜单沿用原操作。

打开对话框时，原姿态经过短暂骨骼混合过渡到坐姿，之后仍一直保持思考坐姿；说话时保留坐姿并带嘴部动作。关闭对话框后平滑回到待机。快速再次点击、拖动或开聊会取代旧过渡，旧动作结束不会把新状态拉回去。

原资源没有单独的提起或落地动画；这些是基于既有头颈、躯干和四肢骨骼的程序姿态。原始 Spine 文件、相机范围和人物比例不变，PNG 回退模式维持基本操作而不承诺相同的骨骼效果。上述交互不新增语音或模型调用。
